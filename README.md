\# Maven Demo Project



This project is a small \*\*Java\*\* application built with \*Maven\*. It started as a

factorial calculator and now uses the \*\*\*Apache Commons Lang\*\*\* library to

transform text.



\## How to build



Maven downloads the dependencies and builds the jar with one command:



```

mvn clean install

mvn exec:java -Dexec.mainClass="com.example.App"

```



\## What it does



\- Calculates the factorial of a fixed number

\- Converts text to upper case and swaps its case

\- Centers, abbreviates, and rotates a message
